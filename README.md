# PROYEK KOPI-NUSANTARA
Modul Praktikum Pemrograman Internet I - Sistem Informasi SI USTJ

## NAMA PROYEK
Sistem Informasi Pemesanan Kopi Nusantara

## HALAMAN PENGGUNA
- index.html: Beranda (Navbar, Promo, Mengapa Memilih Kami, Testimoni <article>)
- menu.html: Menu dan Daftar Harga
- pesan.html: Form Pemesanan dengan Validasi dan Perhitungan Total Otomatis
- kontak.html: Kontak dan Jam Buka

## HALAMAN ADMIN
- admin/dashboard.html: Dashboard Admin (Sidebar, 3 Kartu Ringkasan)
- admin/pesanan.html: Tabel Data Pesanan dengan fitur Pencarian dan Tombol Selesai
- admin/tambah-menu.html: Form Tambah Menu dengan Validasi

## FITUR JAVASCRIPT
- Perhitungan total otomatis & diskon 10% untuk jumlah >= 5 di pesan.html
- Validasi form pemesanan & form tambah menu
- Filter pencarian tabel interaktif & tombol ubah status pesanan menjadi Selesai (warna hijau)
